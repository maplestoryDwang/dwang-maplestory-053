# 服务端乱码文本替换表（UTF-8）
#
# 用途：有些服务端消息发到客户端时每个字已经变成 ?（包里就是 3F 3F 3F），客户端无法还原原文。
#       把这种消息按 [整串逐字节完全相等] 替换成中文写在这里，格式：
#
#           "游戏里看到的那串乱码" = "要显示的中文"
#
# 规则：只有完全一致才会替换，所以任何正常字符串（包括所有中文）都不会被影响。
# 现状：2026-09-13 服务端已自行修好（读 WZ 时用了韩文编码），本表留空，不替换任何东西。
#       左侧乱码可以照抄 DebugView 抓取里 packet raw 那一行的 out="..." 内容。
