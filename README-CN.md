## 📌 项目简介

**GMS v053** 是一个基于 **北斗 (v083)** 架构二次开发的国际服冒险岛（Global MapleStory）服务端项目。

本项目的核心目标是精准还原早期国际服纯粹、经典的冒险体验——涵盖摇骰子决定属性、原汁原味的经典四大职业（战士、法师、飞侠、弓箭手）、四转技能体系以及原生游戏机制；同时维护一份干净清晰的代码库，用于深入分析封包与协议交互。

---

## 🎯 项目目标

1. **原汁原味记忆还原**：完美还原童年记忆中的冒险岛风味。相比市面上常见的特色魔改 v083 版本，本项目剥离了冗余的自定义内容，追求纯粹的 v053 游戏体验。
2. **底层协议与封包研究**：通过对客户端交互与状态掩码的深度解析，为后续高版本服务端修复与封包解析打下坚实基础。

## ⚖️ 设计机制与原生限制说明

1. **100% 原生内容**：拒绝任何魔改！只还原原生的游戏内容。若需要特色功能，建议选择北斗或其它定制版本。
2. **地图范围**：暂不包含 CMS 特有的上海地图（后续视情况考虑加入）。
3. **NPC 交互**：需严格双击 NPC 触发对话（本版本不支持空格键交互）。
4. **宠物系统**：遵循原生单宠物装备规则（不可同时装备多只）。
5. **掉落概率**：野外任务道具掉落率将根据实际体验进行动态调整。
6. **人物动作**：原生暂不支持下跳（`下 + 跳`），后续评估是否通过客户端插件调整。
7. **角色栏位**：未扩展角色 Slot，默认保持原生 3 个角色栏。
8. **技能效果修复**：针对客户端原本存在 BUG 导致导入后无法显示的技能，采用相似技能逻辑进行替代实现，以达成匹配的技能描述与效果。

## 🐛 已知问题与北斗差异

### 已知问题
- [ ] **宠物过滤**：尚未修复/验证（该版本协议中似乎缺失相关逻辑）。
- [ ] **状态掩码**：部分 `MapleBuffStat` 位掩码值仍在进一步测试与确定中。
- [ ] **脚本事件**：当前已关闭所有副本与地图脚本事件，等待后续统一修复与重构。

### 相比北斗（Upstream）的改动差异
* **去除特色魔改**：删除了北斗特色物品、北斗书、回退卷轴等非原生内容。
* **地图与脚本精简**：因仅保留经典四职业，删除了无法跳转的地图节点与相关脚本事件。
* **封包解析修复**：修复了原北斗端中部分存在错误的封包反序列化逻辑。
* **技能逻辑修复**：修复了原北斗端中部分存在逻辑异常的技能处理句柄。
* **任务点数机制**：保留 `quest_point_per_quest_complete` 配置，完成任务可增加人气度。
