# 注意事项
1. 没有任何魔改！！！只还原原生的游戏内容。更多内容建议选择北斗或其他版本。
2. 没有CMS的上海地图，后面考虑加入。 
3. NPC都是需要双击才能触发，没有空格键交互 
4. 宠物只有一只，不能装备多只
5. 游戏任务道具的野外爆率看情况调整
6. 没有下跳，后面看情况要不要插件调整
7. 没有角色slot新增，默认就是3个角色
8. 疑是客户端原本BUG导入无法显示的技能问题，使用相似技能以实现技能描述的效果
