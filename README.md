# 目的
还原原生的冒险回忆，相比较GMS083这个项目更符合小时候的记忆中的味道。丢骰子、经典四职业：战士、法师、飞侠、弓箭手、同时又有四转职业技能，这是我的回忆，每个人玩的时间不同，这是我小学的回忆，现在想完全还原它。
同时对客户端有一个比较深刻了解，后续修复高版本对封包理解有一定作用。

# 注意事项
1. 没有任何魔改！！！只还原原生的游戏内容。更多内容建议选择体验北斗。
2. 没有CMS的上海地图，后面会加入。 
3. NPC都是需要双击才能触发，没有空格键交互 
4. 宠物都是只有一只，不能装备多只
5. 游戏任务道具的野外爆率看情况调整

# 北斗差异
1. 删除所有不是原生的东西。包括回退卷轴 
2. 只有四职业导致部分地图无法跳转
