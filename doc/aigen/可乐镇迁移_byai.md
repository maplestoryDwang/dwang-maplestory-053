## 八、NPC 9001000（可乐熊管理者）入口 / 出口脚本

新增 `scripts-zh-CN\npc\9001000.js`（6.3 KB），参考导游妮妮 `9000020.js` 的实现（`saveLocation` / `peekSavedLocation` / `getSavedLocation`，存档点键换成 `COKETOWN`）。

| 场景 | 行为 |
|---|---|
| 可乐村以外（各大城镇，玩家自行召唤 9001000） | 开场白 → 目的地列表（可乐镇 / 可乐滑雪营 <黄> / 可乐山峡Ⅰ / 可乐巨人树林）→ 两页介绍 → 免费传送（传送前记录出发地图到 `COKETOWN` 存档点） |
| 可乐村地图内（`219000000`~`219020301`，NPC 在可乐镇 `219000000` 的 `1014,267`） | 菜单：①离开可乐村，回到出发前的地图（无记录则回射手村 `100000000`）；②去可乐村其他地方（直接进目的地列表，不重复开场白）；③再多待一会儿 |

- 目的地到达口统一用各图的 `sp`（索引 0）。
- 判断“是否在可乐村”用地图号范围 `219000000`-`219020301`，不依赖地图列表。
- 村内传送时**不会**覆盖 `COKETOWN` 存档点（避免把可乐村地图存成出发点）。
- 已用 Node 桩模拟 5 条对话路径（城外选点传送、村内离开、村内转场、村内停留、取消对话），流程与 `warp / dispose` 调用均正确；`node --check` 通过。
- **生效**：重启服务端即可（脚本热更需重启）。
