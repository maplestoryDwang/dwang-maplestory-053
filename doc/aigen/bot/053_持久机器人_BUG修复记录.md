## 2026-11-25 跨图和停服存档

- 游戏内确认 `!botportal out02` 能让 Bot 从 100000001 跳上平台并过图。用户同时报告有过图异常。现有堆栈属于停服，普通过门的 changeMapInternal 路径没有直接调用角色存档，过图异常待独立日志确认。
- 停服时 PersistentBotAdapter 调用原有 Character.saveCharToDB。无客户端上线绕过了真人账号视图初始化，updateCharacterEntry 调用 World.registerAccountCharacterView 时取到空映射。异常发生在打开数据库事务之前，跳过本次存档。修复为在已有锁内按需创建账号视图，移除不存在的视图条目视为无操作。
- 持久化回归用例：过门到 100000000 后正常停服并重启，用同一角色 ID 核对保存后的地图和出生点。技能相关改动覆盖技能 ID、等级、精通等级和删除后的回读。背包相关改动覆盖新增、消耗、移除、数量、栏位和装备属性。使用现有角色存档事务，核对真实重载结果与错误日志。技能或物品丢失目前属于待验证风险。
