## 2026-11-25 跨图和停服存档

- 游戏内确认 `!botportal out02` 能让 Bot 从 100000001 跳上平台并过图。用户同时报告有过图异常。现有堆栈属于停服，普通过门的 changeMapInternal 路径没有直接调用角色存档，过图异常待独立日志确认。
- 停服时 PersistentBotAdapter 调用原有 Character.saveCharToDB。无客户端上线绕过了真人账号视图初始化，updateCharacterEntry 调用 World.registerAccountCharacterView 时取到空映射。异常发生在打开数据库事务之前，跳过本次存档。修复为在已有锁内按需创建账号视图，移除不存在的视图条目视为无操作。
- 持久化回归用例：过门到 100000000 后正常停服并重启，用同一角色 ID 核对保存后的地图和出生点。技能相关改动覆盖技能 ID、等级、精通等级和删除后的回读。背包相关改动覆盖新增、消耗、移除、数量、栏位和装备属性。使用现有角色存档事务，核对真实重载结果与错误日志。技能或物品丢失目前属于待验证风险。

## 2026-11-25 攀爬时人物被梯绳遮挡

用户确认跳抓攀爬成功，但旁观客户端把 Bot 画在梯绳后面。053 IDA 的 CMovePath::Decode（0x59721D）把移动片段中的 16 位平台字段保存到路径状态。sub_732894 按有符号数解析：正值通过 GetFoothold 查平台，负值取反后调用 sub_732A54 查梯绳。梯绳分支读取结构偏移 +24，更新向量控制 page，并通知 owner；sub_597985 的真人路径生成也会把梯绳 ID 取负写入同一字段。

修复为攀爬中发送负梯绳 ID，跳抓末帧将规划器内部挂绳节点映射成负梯绳 ID，落到平台后恢复正平台 ID。独立攀爬回归命令的中间帧和挂绳静止帧同步修正。以 ladderRope ID=1 为例，攀爬字段应为 FF FF。Java 21 编译通过，用户随后确认层级修复通过。本次实际分析了 053 IDA，083/095 MCP 当时连接被拒绝。

## 2026-11-25 射手村连续地面被竖段误阻挡

用户报告 100000000 从 (526,274) 不能到 (159,274)。WZ 的 113 段为 X=492、Y=258..276，上端连接台阶，下端没有连接地面；此前把所有竖段当实墙。现在根据下端 prev/next 连通关系筛选阻挡墙，连续地面及重合端点的 WALK 连边遵守地面拓扑。跳落动作增加 0.15 秒选路成本，避免浮点耗时近似相等时在连续平地绕跳。

Java 21 编译通过。完整 100000000 WZ 离线验证两方向均为 [WALK]。实墙分类回归保留下端连地竖段。用户随后确认该位置可达。
