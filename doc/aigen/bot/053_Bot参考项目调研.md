## SoloMapling：1.2 的主要参考

源码位于 E:/game/ms/gms053/ai/SoloMapling。README 介绍了录制回放、图寻路和传送门跨图三条路径。源码有两组值得分开读的实现。

- ArtificialPlayer/BotMovementSystem/NavigationSystem 下的 MapGraph、PathFinder、PortalConnection 展示同图最短路径和传送门连接的表达。053 已有 Dijkstra，可保留现有求路逻辑，将输出从坐标序列扩展成带动作类型、起止平台和预期状态的路段。
- ArtificialPlayer/GCMoveSystem 下的 BotNavigationMapLoader、BotNavigationGraph、BotNavigationManager、BotPhysicsEngine、GCMovementDriver 和 MovementPlan，适合对照地图加载、图构建、物理、执行的职责。平台、跳落、梯绳连边先用 053 地图数据和客户端样本验证。083 的速度、重力、攀爬常量，以及移动帧录制文件均只用于比较结构和采样方法。
- GCWorldGraph、GCTravel、GCPortals 与 NavigationSystem/BotScriptedWarp 可用于区分跨图规划和实际过门。地图间边应保留源门户、目标地图和落点。普通门户接现有 053 过门入口，有脚本或条件的边明确记录条件是否受支持。

对最终目标，BotTickService 与 GrindBrain、GrindLoot、TrainingMapChooser 可参考行为循环、目标筛选、练级地图和拾取优先级。组队任务的编排可以参考目标拆分与失败恢复。当前 1.7 自主任务仍需基于本服 QuestV2 的条件、奖励和多轮脚本。仓库带 AGPL-3.0 许可证，若后续引入源码，先核对适用许可及保留要求。

## 北斗 GMS083：宿主适配和联调参考

发布目录为 E:/game/ms/gms053/ai/GMS083-beidou-bot-release。BeiDou.jar 同时包含 soloMapling 包与 org.gms.bot，且本地提供反编译目录。它可用于比较两套服务端宿主怎样接同类 Bot 行为。包中存在大量 083 地图动作录制资源，样本的地图几何、平台 ID 和动作编码需以 053 为准。

- 反编译/org/gms/bot 下的 NativeBotHost、HeadlessClient、BotRegistry、BotPopulationHostAdapter 提供创建、挂地图和回收的边界参考。当前 053 持久化以已有账号角色为主，沿用 PersistentBotAdapter 和原有角色存档。
- BotCombatCanary、GoldenTraceComparator 可借鉴单角色联调和事件轨迹比较。053 可以为路线规划、每段执行、过门与落地记录角色、地图、起止平台和失败原因，重放对照测试时过滤时间戳等非确定字段。
- BotGrowthHostAdapter 的 capture/restore、BeiDouTrainingMapAdapter、BeiDouMonsterTargetSelector 可用于思考后续成长适配与目标选择。053 的角色数据和怪物结算仍通过现有业务入口。发布包与反编译结果用来核对设计和测试方法，未确认其源码再分发授权。

1. 先跑通已有步行路线到实际移动的闭环。服务端更新位置及可见性，旁观客户端看到 053 动作，最后同步站姿和 foothold。

3. 建立普通门户的跨图路径，验证抵达目标入口、返程及失败原因。脚本门按本服条件逐类扩展。
4. 游戏内验收覆盖同图走到目标、上下层、往返跨图及不可达，分别记录所选路线、服务端最终坐标和旁观表现。
