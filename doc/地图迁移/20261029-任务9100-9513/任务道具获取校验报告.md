## 二、校验口径

1. 从 `Check.img` 的 `0`（接取）/`1`（完成）节点取必需道具与必需怪物；从 `Act.img` 取奖励和 `nextQuest`。
2. 获取途径按优先级核对：`Act.img` 其他任务给的道具（含接取即得）→ `drop_data` → `drop_data_global` → `reactordrops` → `shopitems` → `scripts-zh-CN` 脚本产出。
3. 可完成 = 所有必需道具都有途径 + 前置任务可完成 + 必需怪物/NPC 存在。
4. `count=0` 的道具按"接取时不能持有"处理，不算必需道具（例如 9210 不能带着爱情巧克力棒再接）。
5. 外部任务（3623、8517 等，不在 131 个内）默认视为可完成；如被改动需复核。
