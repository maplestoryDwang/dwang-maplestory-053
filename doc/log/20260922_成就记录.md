# 第一部分：初版成就系统完整实现方案

## 一、 系统设计与痛点解决方案

- **设计初衷**：

    1. 解决角色初始 HP/MP 过少的生存痛点（通过部分成就/彩蛋直接提升上限）；

    2. 增强经典 NPC 的交互性与存在感，避免纯控制台化的冷冰冰体验；

    3. 提供全方位随身便捷工具（如通过特定道具/脚本触发对话，无需频繁跑图）。

- **基础阶段（怪物减伤）**：

    - 全服怪物共计 830 种，成就进度将逐步降低怪物 HP，最终实现 100% 减伤/削弱。

## 三、 十大彩蛋机制 \(SPECIAL\_EGG\) 与最终终局

### 详细彩蛋列表

1. **装备枫叶盾**：穿戴枫叶盾 \(`1092030`\) 触发记录。

2. **品尝特殊美食**：使用绿豆粥 \(`2022001`\) 或空气零 \(`2022040`\) 触发记录（修正扣血机制为十倍，使其正常使用）。

3. **海上猎手**：在乘船途中击败蝙蝠魔 \(`8150000`\)。

4. **匠人神韵**：通过 Forge/Maker 系统成功制作一件带自己署名的装备。

5. **高级桑拿修养**：在高级桑拿房 \(`105040402`\) 挂机静坐，每分钟提升 1 点 MaxHP / MaxMP 上限。

6. **屡败屡战**：累计掉落墓碑死亡 8 次。

7. **强者证明**：完成四转职业突破任务（Quest `6904`, `6914`, `6924`, `6934`）。

8. **上古遗泽**：雪域完成上古魔书任务（Quest `3035`），解锁 NPC 炼金术士（可在 NPC `2020005` 处用金币直接购买矿石母矿）。

9. **形象焕新**：成功更换一次发型、脸型及肤色。

10. **极限跳跃**：通关三大跳跃地图（地铁、忍苦、沉睡，完成 Quest `2050`\~`2057`），永久获得轻功加速 Buff 状态。

### 终局奖励与自由转职 \(自由转职\.js\)

- **开启条件**：十个彩蛋全部完成 **且** 角色已达到 4 转。

- **终局特权**：

    - **自由转职**：在四转教官 NPC（`2081100` 战士 / `2081200` 法师 / `2081300` 弓箭手 / `2081400` 刺客）处自由切换同系职业。

    - **配套服务**：自动返还并重置 AP/SP，个人 NPC 处提供自动加点服务。

    - **感言书信**：所有成就全满后，获得一封专属信件，记录玩家在这个冒险世界中的传奇生涯。

# 第二部分：其他系统实现与开发变更日志

## 一、 服务端功能拓展与修复

### PlayerNPC \(玩家雕像\) 系统

- **生成机制**：打败区域 BOSS 后在荣誉之石旁生成个人雕像（使用 `9901000`\~`9901319` ID 节点）。

- **形象同步**：调用 `PlayerNPC#updatePlayerOutfit`，支持玩家后续换装同步更新。

- **每日更新控制**：引入 ExtendValue 全局每日刷新机制（基于 `saveOrUpdateCharacterExtendValue`），控制每日奖励领取与远程通话次数。

### 吸怪与全屏拾取能力

- **触发装备**：蒙特鸠披风 \(`1102139`\) / 卡帕莱特披风 \(`1102140`\)。

- **实现方式**：复用底层 ASM 代码，在 NPC 2040050 处兑换，穿戴后获得吸怪与全屏拾物能力（仅限生效一种）。

### 数据清洗与数据库修复

- **商城物品拿取问题**：修复商城装备在 `inventoryitems` 中 `type=3` \(冒险家仓库\) 且连表 `inventoryequipment` 时的逻辑错乱，解决商城装备提取异常。

- **脚本迁移**：迁移并理顺服务端数据更新脚本。

### 辅助通用逻辑

- **通用分页功能（JS 脚本模板）**：

    - 定义 `PAGE_SIZE = 10`，使用高位虚设 ID（`9000001` 上一页 / `9000002` 下一页）拦截翻页操作并重置 `status`。

- **地图召唤与清理机制（未完成）**：

    - 检测切换地图事件，若上一次进入地图的玩家非当前玩家，自动清空旧怪物（不触发掉落）并重新刷怪。

    - 目的：不同进度显示的HP是要相同

## 二、 客户端与 WZ 资源修正

1. **地图与镜头修复**：

    - 修复玩家在地图边缘时镜头仍强制锁定在画面中间的问题，调整边界让玩家能正确显示在地图角落。

2. **NPC 与脚本关联（WZ 节点）**：

    - 在 NPC 的 WZ 节点中补全 \`\` 与 `scriptInfo`，使 NPC 点击时能够正常弹出脚本对话。

    - 补充冒险岛运营员 \(`9010000`\) 的 `4th_mapleWeapon` 脚本关联。

3. **无效跳转与怪物清理**：

    - 清理导游妮妮 \(`9000020`\) 等 NPC 中指向不存在地图的跳转节点。

    - 暂时移除未实现的怪（如绿波普 `9400510`）。

4. **道具显示**：

    - 修复手机（无需穿戴限制直接使用）与缩地石的 UI/道具展示。
